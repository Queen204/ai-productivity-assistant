# AI Business Buddy

Build a modern, clean, professional and responsive SaaS-style web application called “AI Small Business Assistant”.

The purpose of the application is to help small businesses improve productivity by using AI to manage communication, meeting information, tasks and research.

DESIGN STYLE:

Use a clean, modern and professional design similar to a high-quality SaaS platform. Use professional typography, modern cards, rounded corners, subtle shadows, clear icons, consistent spacing and an easy-to-use interface.

The application must work well on both desktop and mobile.

MAIN DASHBOARD:

Create a professional dashboard with:

- A sidebar navigation

- Dashboard

- Smart Email Generator

- Meeting Notes Summarizer

- AI Task Planner

- AI Research Assistant

- About

The dashboard should have a welcome message:

“Welcome to AI Small Business Assistant”

Display four feature cards with descriptions and “Open Tool” buttons.

REQUIREMENT 1: SMART EMAIL GENERATOR

Create an AI email generator that allows the user to:

- Enter the purpose of the email

- Enter the recipient

- Enter important information

- Select a tone: Formal, Friendly or Persuasive

Add a “Generate Email” button.

The output should contain:

- Subject

- Greeting

- Professional email body

- Closing

Include:

- Copy button

- Regenerate button

- Clear button

REQUIREMENT 2: MEETING NOTES SUMMARIZER

Create a meeting notes summarizer.

Allow the user to enter:

- Meeting title

- Date

- Participants

- Long meeting notes

Add a “Summarize Notes” button.

The AI output should include:

- Meeting summary

- Key discussion points

- Decisions made

- Action items

- Deadlines

Include Copy, Regenerate and Clear buttons.

REQUIREMENT 3: AI TASK PLANNER / SCHEDULER

Create an AI task planner that helps users organize their work.

Allow users to enter:

- Task name

- Deadline

- Priority

- Estimated time

Priority options should be:

- High

- Medium

- Low

Add a “Create My Schedule” button.

The AI should:

- Prioritize tasks

- Organize tasks according to urgency and importance

- Create a daily or weekly schedule

- Show deadlines

- Recommend the order in which tasks should be completed

Include Generate, Regenerate and Clear buttons.

REQUIREMENT 4: AI RESEARCH ASSISTANT

Create an AI research assistant.

Allow users to enter a research topic or question.

Provide options for:

- Summary

- Key points

- Insights

- Recommendations

- Research questions

Add a “Research Topic” button.

The output should display:

- Topic summary

- Key points

- Insights

- Recommendations

- Suggested research questions

- Areas for further research

Include Copy, Regenerate and Clear buttons.

AI-GENERATED RESPONSES:

All four features must have clearly separated input and output sections.

Show a loading indicator while the AI is generating a response.

Show a helpful error message if something goes wrong.

RESPONSIVE DESIGN:

Make the application fully responsive for:

- Desktop

- Laptop

- Tablet

- Mobile

On mobile, convert the sidebar into an easy-to-use mobile navigation menu.

PROFESSIONAL UI/UX:

Make the application look like a real business SaaS platform, not a basic school project.

Use:

- Professional buttons

- Modern cards

- Clear headings

- Helpful placeholder text

- Icons

- Empty states

- Loading states

- Error messages

- Success notifications

- Consistent design throughout

RESPONSIBLE AI:

Include a visible disclaimer:

“Responsible AI Notice: AI-generated information may contain errors or inaccuracies. Users should review and verify important information before making business decisions or relying on AI-generated content.”

Also advise users not to enter confidential or sensitive business information.

ABOUT PAGE:

Create an About page explaining:

- What the AI Small Business Assistant is

- The problem it solves

- The four AI features

- How it can improve productivity

- The benefits of using AI in small businesses

PROJECT GOAL:

The goal of this project is to demonstrate how AI can help small businesses save time, improve communication, organize tasks, summarize information and support research.

IMPORTANT:

Build an interactive and functional web application, not just a static design.

The project should demonstrate:

- Problem relevance

- Good prompt engineering

- Functionality

- Innovation

- Responsible AI practices

- High-quality professional presentation

Make all navigation, forms, buttons and interactions work properly.
